# lit-club-website
This is the Kanagawa University Literature Club's introductory website.

## 部誌・作品集の追加方法

1. `books.html` を開き、`const BOOKS = [` を探します。
2. 一冊分の `{ ... }` をコピーし、配列の先頭または末尾へ追加します。冊と冊の間にはカンマが必要です。記載した順に表示されます。
3. 誌名・紹介文・発行年などを変更して保存します。編集する項目の説明は `BOOKS` の直前にもあります。

```js
{
  title: "新しい誌名",
  heading: "文藝部誌 第13号『新しい誌名』",
  category: "部誌",
  year: 2027,
  published: "2027年4月",
  price: "500円",
  members: "6名",
  description: "作品紹介文を入力します。\nここから次の行です。",
  cover: "images/issue13.jpg",
  color: "#294c57",
  contents: [
    { title: "収録作品名", author: "筆名", genre: "短編小説", page: "4" }
  ],
  excerpts: [
    { title: "紹介する作品名", author: "筆名", text: "公開したい短い抜粋。\\n次の段落の文章。" }
  ],
  shopUrl: ""
}
```

- **表紙**：リポジトリの `images` フォルダに画像をアップロードし、`cover` にパスを記入します。表紙が未定なら `""` にしてください。仮表紙が自動表示されます。
- **目次**：`contents` 内に作品名・筆名・ジャンル・ページ番号を追加します。`page` は空欄でも構いません。「掲載作品はこちら」から目次を開けます。
- **一部抜粋**：`excerpts` 内に紹介する作品名・筆名・公開してよい文章だけを記入します。改行には `\n` を使います。抜粋はスクロール時に段落ごとに登場します。
- **目次・抜粋を載せない場合**：それぞれ `contents: []`、`excerpts: []` にするとその欄を表示しません。
- **本文の扱い**：販売する作品の全文を入力して非表示にする方法ではありません。サイトのデータには公開する短い抜粋だけを記入してください。PDFリンクは設けていません。
- **販売先**：BOOTHなどのページURLを `shopUrl` に記入します。
- **未定のリンク**：`""` にするとボタンは出ません。販売先が空欄なら販売先は準備中と表示します。
- **発行年**：`year` は `2027` のように数字で記入します。年の選択肢は自動で増えます。
- **仮表紙の色**：`color` は `#294c57` のような6桁のカラーコードです。
- **注意**：文字列はダブルクォートで囲みます。文章にダブルクォートを入れる場合は `\"` と書くか、かぎ括弧を使います。

ホームの文章は `index.html` の各セクションで編集できます。公開前に仮の内容と制作中表記を見直してください。

GitHubへの変更後、Cloudflareのビルドが成功すると公開サイトに反映されます。
