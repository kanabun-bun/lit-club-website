## 活動紹介・修正・削除（追加）
- 「活動紹介（ホーム掲載）」はホームの「第一章／部のこと」本文に表示します。既存文章を初期データとして用意します。
- 登録済み作者・作品の一覧に「修正」「削除」を追加しました。
- 作品名、作品の掲載名、作者の選択、作者の管理名・所属を修正できます。
- 作者の管理名変更では過去作品の掲載名を変えません。作品側で修正してください。
- 作者に作品が残っている場合は削除を拒否します。
- 作品削除ではPDFと関連紹介も削除します。確認ダイアログを表示します。
- 一言・活動・店舗・イベントなどの記事も削除できます。
- 部誌目次はテキストなので作品変更/削除後は別途修正してください。
- このCRUD拡張はローカル版で実装。本番Worker APIへの移植は接続工程です。

# 保存付きローカルデモの起動

追加契約・支払い方法登録・Cloudflare設定は不要です。Python 3だけで動きます。

1. 開発ブランチのZIPを展開します。
2. ターミナルで展開したフォルダへ移動します。
3. 次を実行します。

```sh
python3 cms/local_demo.py
```

http://127.0.0.1:8000/ を開きます。終了はControl+Cです。
既存のpython -m http.serverが動いている場合は先に停止してください。

- 部員パスワード: `member-demo`
- 管理者パスワード: `admin-demo`
- 起動時は既存の公開文章・部誌目次を初期データとして登録します。添付PDF全文は含めません。
- データは `cms/.local-demo/demo.sqlite3`、PDFは `cms/.local-demo/pdfs` に保存されます。
- 再起動しても保存内容は残ります。ZIPを更新するときは旧版の `.local-demo` フォルダを新版cmsへ移すと引き継げます。
- ファイルはGitの対象外です。公開リポジトリへデータベースや全文PDFを追加しないでください。
- サーバーは127.0.0.1だけに接続します。他のPC・外部からのアクセスを受け付けません。
- これはローカル検証用です。デモパスワードやPythonサーバーをインターネット公開に使わないでください。

## 確認できる流れ
ホーム → 部員の方へ → 部員ログイン → 管理者へ → 管理者ログイン。
部員の一言を選んで編集 → 下書き保存では公開ページは変わらない → 公開すると「部員のひとこと」に反映。
作品紹介は一覧と詳細、部誌は目次、店舗・イベントは既存デザインの案内ページに反映します。
別タブへ移った後に戻ると公開ページは再読み込みします。手動の再読み込みでも確認できます。

作者を登録 → 作品情報を登録 → 下部の「作品PDFと会員公開」でPDFを選ぶ → 会員公開。
部員ページで検索してPDFを閲覧できます。PDFは50MB以内、合計8.5GBを超える登録は拒否します。
全文検索は手入力の検索本文を対象にします。PDF自動抽出・OCR、画像アップロード、目次の作品ID選択GUIは未実装です。
PC内のディスク容量・R2上限とは別の検証です。R2の操作回数/課金制限を実装したわけではありません。
